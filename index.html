Thêm bộ đề / môn học mới

Dán nguyên văn đề trắc nghiệm theo định dạng Moodle (có dòng Select one:, các đáp án a. … b. … và dòng The correct answer is: …). Hệ thống tự tách câu hỏi và đáp án đúng.
Tải lên file .json (theo schema bên dưới) hoặc file .txt đề Moodle. File JSON có thể export sẵn từ môn khác để commit vào repo GitHub.
Schema JSON:
{ "name": "Tên môn", "questions": [ { "q": "Câu hỏi?", "options": ["A","B","C"], "answer": 0 } ] }
(answer là chỉ số đáp án đúng, bắt đầu từ 0)
